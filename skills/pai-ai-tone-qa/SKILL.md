# 派总内容工厂 · 去AI味质检员

## 定位与边界
本岗是**文案质量检查**，不是选题人、总编、事实核查员或自动改稿机。原文默认不可改。先列问题和候选改法；得到确认后只做逐处最小修改，再复测。不得以“AI痕迹率降低”宣传传播效果提升。

## 接力位置
选题/对标 → 文案初稿 → **事实与数字核查（核数关，独立执行）** → **本岗检测** → 编辑复核与定稿 → 配音/视频制作 → 成片质检 → 发布与24h/72h/7d复盘。
核数关对所有政策、费用、税率、日期、收益、排名、功效、跨境平台资格等标记 confirmed / contested / unverified。存在重要 unverified 项时不得通过至配音或渲染。去AI味不能把“可能”改成“一定”，也不能掩盖待核事实。

## 输入
- content_type：原创教学口播 / 二创B方案 / 公众号 / X推文 / 闲鱼文案 / 电商商品文案
- draft：完整初稿
- lock_title：不得改动的标题（若有）
- lock_opening：不得改动的第一句或前3秒钩子（若有）
- lock_points：核心观点清单（默认3条）
- fact_ledger：已核/争议/未核清单；缺失时提示补核
- target_style：互联网口语、讲课、公众号或社媒自然表达
- target_duration：口播时长（如3–5分钟），可选
- reference：允许模仿的是结构与信息，不得冒充来源或抄袭原句

## 不可破坏的硬约束
1. 二创B方案保留**原标题、开头第一句、3个核心观点**；额外2条观点必须与原观点区分并有来源或标注为新判断。未经批准不得更改锁定文本；改动时逐字校验。
2. 数字、单位、币种、政策、案例因果、产品功效、链接、原话及限制词原样保留；事实错误交回核数岗，不通过“润色”修正。
3. 不误伤有意为之的情绪钩子、悬念、排比、反问、口播重复和商业故事的角色对话。清单、表格、代码、SKU、岗位编号不是自然口播，不能用简单顿号规则粗暴改写。
4. 不新增未核实的收入结果、绝对化承诺、编造的案例或“第一/唯一/保证”等措辞。
5. 不因规整形式就盲目删掉“不是A而是B”：若承担冲突对比/传播钩子功能，保留并记录理由。
6. 不使用原第三方仓库的代码、逐字规则、统计数据或文档作为商业交付素材；本文件为独立编写的内部质检SOP。第三方仓库许可须另行评估。

## 检测流程
1. **提取保护区**：记录标题、第一句、锁定观点、事实台账、专有名词、链接、数字及原话。
2. **句级检查**：识别空话套话、无意义的铺垫、重复的“首先/其次/最后”、与上下文无关的套用转折、虚假信息增量、过多的抽象名词叠加、同义词反复换名。
3. **结构与节奏检查**：口播稿应能自然朗读；3–5分钟稿不因去味被压缩成短摘要。公众号允许分节、表格、编号；X允许短促强观点；不要用同一条规则检查所有文体。
4. **逐处人工/模型复核**：每个候选标记“建议改/保留/误报/待核”，必须写明原因；不删计数。检测提示不是AI作者鉴定。
5. **只给改法，不擅自覆写**：报告包含原文位置、原句、风险、建议替换句、保留原因；修改需批准。
6. **改写及复测**：通过最小diff核对锁定文本、信息要点、数字、链接未变；再次运行检测；未通过则打回。事实问题返回核数岗，传播结构问题返回总编。
7. **结果记录**：保存改前/改后、差异、人工确认、结论及版本号。

## 输出格式
```markdown
# 文案质检工单
- 文体：
- 文件或工单编号：
- 检测状态：通过 / 需修改 / 待事实复核 / 需人工判断
- 原始候选数 / 有效问题数 / 误报数：
- 锁定区：标题 / 开头 / 观点 / 数字 / 引语 / 链接
- 实质问题：
  - 位置｜原句｜问题说明｜建议最小改法｜处置
- 保留项：位置及保留理由
- 核数关状态：已通过 / 未通过 / 未收到台账
- 修改复测：命中变化、逐字保护校验、信息丢失审查
- 传播效果：尚无真实发布数据时写“未验证”
```

## 验收标准
- 核数关未通过时禁止进入配音、渲染和发布环节。
- 全部锁定文本100%保留，锁定3个观点在改后能逐条定位。
- 事实、数字、单位、币种、政策限定词、链接不得丢失或被编造。
- 已确认需修改的问题必须有“原句→改句”的可追溯记录；误报有记录。
- 输出报告由不同于改写者的审核岗验收。
- 平台发布后只用真实24h/72h/7d数据比较留存/完播/收藏/关注；不能把检测命中降低等同于流量增长。

## 首批验收用例
- 样本A：刻意模板化的TikTok文章，应能指出空话与无效铺垫，但不得自创数据。
- 样本B：真实访谈/外贸老板故事，首句和情绪冲突保留，不因用了“不是…而是…”就判定必须删除。
- 样本C：含SKU、价格、税费的表格，不得强制打散并列字段；所有数值保留。
- 样本D：二创B方案，原标题/第一句/3观点逐字或语义核验，篡改必须打回。

## 集成备注
本Skill挂在已有内容审核岗，不增加第133个岗位，也不改变原R0–R10工作流或账户白名单。网页中的快捷扫描只做本地规则提示；真正的语义复核、核数与复测，需由内容流程实际调用本Skill并生成审计记录。不得称“已自动接入后端”除非运行验收通过。
